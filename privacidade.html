Política de Privacidade

Aplicativo ALS Tributário · Última atualização: 20 de novembro de 2026

1. O que é o aplicativo

"ALS Tributário" é uma ferramenta interna, de uso exclusivo do titular do canal ALS Tributário no YouTube, usada para gerenciar esse próprio canal. O aplicativo não é oferecido ao público nem a terceiros.

2. Serviços de API do YouTube

O aplicativo utiliza os Serviços de API do YouTube (YouTube Data API v3 e YouTube Analytics API). Ao usar o aplicativo, o usuário concorda com os Termos de Serviço do YouTube. O tratamento de dados pelo Google é regido pela Política de Privacidade do Google.

3. Dados acessados

Com a autorização do titular, o aplicativo acessa apenas dados do próprio canal ALS Tributário:

  • envio de vídeos produzidos pelo próprio canal;
  • leitura e edição de títulos, descrições, miniaturas e agendamento desses vídeos;
  • leitura de dados e métricas do canal (YouTube Analytics), para planejamento de conteúdo.

O aplicativo não acessa dados de outros canais ou usuários e não coleta dados de espectadores além das métricas agregadas que o YouTube fornece ao titular do canal.

4. Uso, armazenamento e compartilhamento

Os dados são usados apenas para as finalidades acima. As credenciais de acesso e os dados obtidos ficam armazenados localmente, no computador do titular, e não são vendidos, compartilhados ou transferidos a terceiros.

5. Revogação do acesso

O acesso do aplicativo pode ser revogado a qualquer momento na página de permissões da Conta do Google: myaccount.google.com/permissions. Após a revogação, os dados armazenados localmente podem ser excluídos mediante solicitação pelo contato abaixo.
